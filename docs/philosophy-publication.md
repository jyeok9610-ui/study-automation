# 철학개론 1장 웹 반영

2026-11-02

## 제공 범위

OpenStax Introduction to Philosophy의 1장 1.1~1.4를 한국어로 재구성한 네 읽기 페이지와 서술형 문제 16개를 등록했다. 원서 전체 12장 가운데 현재 공개 범위는 1장이다.

- 책: /#/books/introduction-to-philosophy
- 첫 페이지: /#/books/introduction-to-philosophy/pages/what-is-philosophy
- 분야: /#/subjects/philosophy
- 원문 절별 출처, 재구성 사실, CC BY-NC-SA 4.0 이용 조건을 명시했다.
- 원본 옵시디안 문서를 자동 동기화하는 기능은 추가하지 않았다. 검토한 본문·표·문항·해설을 정적 교재 JSON에 반영했다.

## 읽기와 저장

기존 읽기·메모·진도·북마크 구조를 사용한다. 서술형 문제에는 임시 입력란과 접힌 해설·검토 기준을 제공한다. 답은 컴포넌트 메모리에만 두며 페이지 이동·새로고침에 초기화된다. 보관할 생각은 기존 메모에 작성하도록 안내한다. 채점이나 시도 이력은 추가하지 않았다.

철학 사전은 한국어 뜻과 영문 용어를 표시한다. 일본어 읽기·한자·음성 UI는 일본어 책에서 계속 사용한다. 출처 링크는 HTTP(S) 주소만 허용한다.

## 확인 결과

- npm test: 21개 통과.
- npm run validate: 일본어·철학 2권의 형식·출처·목록·노선·개념 연결 통과.
- npm run build: 통과. Zod 의존성의 주석 제거 경고가 있었으며 빌드 실패는 없었다.
- Chromium desktop와 WebKit mobile의 대상 흐름 22사례 확인. 최초 20개 통과 뒤, 용어 사전의 두 검색 결과를 한꺼번에 선택한 테스트 선택자를 고쳤다. 철학 관련 6사례를 다시 실행해 모두 통과했다.
- 철학 네 페이지, 표와 16문항, 해설 토글, 출처, 검색·사전, 임시 답 초기화, 메모·읽음·북마크 유지, 백업의 임시 답 제외를 확인했다.
- 기존 일본어 문항·세 학습 활동·슬라이드 메뉴·이전 백업 호환 흐름을 확인했다.
- 검사 중 페이지 런타임 오류와 가로 넘침을 발견하지 못했다.
- 생성한 화면은 Playwright의 test-results/philosophy-* 아래에서 확인했다. 실제 iPhone Safari 실기기 검사는 별도다.

## 배포

기존 GitHub Pages 배포를 유지한다. master 브랜치의 검토한 파일만 커밋·푸시하면 Deploy library to Pages 워크플로가 검사·빌드·배포한다. dist에는 public/content와 정적 읽기 앱만 포함되며 PC 제작실·원자료·DB는 포함되지 않는다.
